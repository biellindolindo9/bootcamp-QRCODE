## 🧠 Sobre o projeto

Este projeto foi desenvolvido durante um **bootcamp realizado na plataforma DIO**, seguindo as aulas e metodologias propostas ao longo do curso.

A aplicação consiste em um **gerador de QR Code**, onde o usuário pode inserir um texto ou link e gerar automaticamente um código QR correspondente. Esse tipo de aplicação é bastante comum no desenvolvimento web, pois permite transformar informações em códigos escaneáveis de forma rápida e prática.

O projeto foi construído utilizando:
- **HTML**
- **CSS**
- **JavaScript**

Durante o desenvolvimento, foram aplicados conceitos importantes como:
- manipulação do DOM  
- captura de dados do usuário  
- eventos em JavaScript  
- integração com geração de QR Code  

## 🎯 Objetivo

O principal objetivo deste projeto foi **colocar em prática os conhecimentos adquiridos no bootcamp da DIO**, aplicando na prática os conteúdos ensinados nas aulas.

Além disso, o projeto reforça o aprendizado baseado em **metodologias práticas**, onde o desenvolvimento acontece junto com a resolução de desafios e construção de aplicações reais.

## 🎮 Funcionalidade

A aplicação permite que o usuário:
- digite um texto, link ou informação  
- gere um QR Code automaticamente  
- visualize o código diretamente na tela  

## 💡 Considerações

Este projeto representa minha evolução durante o bootcamp, demonstrando minha capacidade de aplicar conceitos de desenvolvimento web na prática, seguindo as metodologias propostas pela DIO e construindo soluções funcionais.
